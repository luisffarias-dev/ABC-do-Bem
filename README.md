# ABC do Bem

## 📖 Sobre o Projeto

O **ABC do Bem** é uma plataforma digital voltada para o impacto social e o apoio à educação básica, criada para conectar voluntários, doadores e iniciativas comunitárias. O objetivo central do projeto é facilitar o acesso a recursos educacionais e promover ações solidárias de forma simples, transparente e acessível.

## 🛠️ Tecnologias Utilizadas

* **Front-end:** React, TypeScript e Tailwind CSS
* **Back-end:** Node.js e Express
* **Banco de Dados:** PostgreSQL

## 🚀 Como Executar

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/abc-do-bem/abc-do-bem.git
   ```

2. **Acesse a pasta e instale as dependências:**
   ```bash
   cd abc-do-bem
   npm install
   ```

3. **Configure as variáveis de ambiente:**
   Copie o arquivo de exemplo para criar a sua configuração local:
   ```bash
   cp .env.example .env
   ```

4. **Inicie a aplicação:**
   ```bash
   npm run dev
   ```
